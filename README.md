# A Model-Driven Methodology for Designing Data-Intensive Architectures

This repository contains the artifacts and tools supporting the methodology for designing data-intensive architectures.

## Repository Structure

The repository is organized into two main folders:

### 1. `replication_package/`
Includes:
- Figures referenced in the article
- Results of the survey conducted to answer the following research question:
	> *Is the SDL sufficiently expressive and usable for practitioners to model real-world application scenarios, even without deep expertise in distributed systems?*

### 2. `tool/`
Contains the tool implementing the proposed methodology, enabling the modeling and design of data-intensive architectures following a model-driven approach.
